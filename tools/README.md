# 🔧 Herramientas y Scripts de Mantenimiento

Esta carpeta contiene scripts de utilidad para mantenimiento, diagnóstico y administración del sistema.

## 🛠️ Scripts Disponibles

### Actualizaciones y Mantenimiento
- **actualizar_header_footer_masivo.php** - Actualiza header/footer en múltiples archivos
- **actualizar_todas_las_paginas.php** - Actualización masiva de páginas
- **reinstalar_completo.php** - Reinstalación completa del sistema

### Diagnóstico y Testing
- **diagnostico_performance.php** - Análisis de rendimiento del sistema
- **test_pages.php** - Pruebas de páginas del sistema
- **verificar_instalacion.php** - Verificador de instalación correcta

### Limpieza y Optimización
- **limpiar_bloqueos.php** - Limpia bloqueos de usuarios
- **limpieza_completa.php** - Limpieza completa de sistema
- **optimizar_bcrypt.php** - Optimización de encriptación de contraseñas

### Seguridad
- **generar_hashes.php** - Generador de hashes para contraseñas

### Base de Datos
- **reiniciar_mysql.bat** - Script para reiniciar MySQL (Windows)

## ⚠️ Advertencias Importantes

1. **Usar con precaución**: Estos scripts modifican datos del sistema
2. **Backup primero**: Siempre hacer respaldo antes de usar herramientas de limpieza
3. **Solo administradores**: Estos scripts solo deben ser usados por personal técnico
4. **Entorno de prueba**: Probar en entorno de desarrollo antes de producción
